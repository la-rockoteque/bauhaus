# Empty results

## 1. Introduction

**In plain words:** An empty result is what a list shows when there is nothing to show. It should say why, and give the user a way forward.

**Precisely:** Pattern · a heading, a hint and one button, arranged in a status region · composes the text primitive and the button; has no style of its own.

## 2. Tokens (consumed)

None of its own. Layout and colour come from the text primitive and the button. Gaps between the three parts are set by the parent through `space.stack.sm`.

## 3. Anatomy

| Part | Status |
|---|---|
| Heading (`Text`, variant heading) | Required |
| Hint (`Text`, muted) | Optional; state the filters that applied |
| Action (`Button`, secondary) | Required when a filter caused the result; optional otherwise |
| Status region (`role="status"`) | Required |

## 5. Usage

### When to use

- When a list, table or search returns zero rows.

### When not to use — and what instead

- When the request failed: show an error with a retry, since "no results" would be false (Nielsen heuristic 9, help users recognise and recover from errors).
- When results are still loading: show the loading state, or a skeleton for a long wait.

### How

- **Content:** say whether nothing exists or nothing matches, and name the filters that applied (Nielsen heuristic 1, visibility of system status).
- **Action:** offer one button that clears the filters (Nielsen heuristic 3, user control and freedom).
- **Accessibility:** put the message in a status region so a screen reader announces it after a filter change (WCAG 4.1.3 Status Messages, AA).
- **Responsive:** let the text wrap; the button stays on its own row below 320 CSS px (WCAG 1.4.10 Reflow, AA).
- **Text arrives as props.** The pattern holds no i18n code (docs/library.md, isolation rule 4).

## 6. Pitfalls and don'ts

| Don't | Why it fails | Basis | Rule id |
|---|---|---|---|
| "No data" with no filters named | Users cannot tell whether to change the filters or wait | Nielsen heuristic 1 | `empty-results.says-why` |
| No way to clear the filters | The user is stuck in an empty view | Nielsen heuristic 3 | `empty-results.offers-exit` |
| A stylesheet in the pattern folder | The pattern drifts from the components it composes | docs/library.md | `empty-results.no-own-style` |
| A silent update after filtering | Screen reader users hear nothing | WCAG 4.1.3 (AA) | `empty-results.announced` |
