# Focus

The Showcase story holds the ring in both themes with its measured contrast, the live rulebook and the accessibility coverage. This guide holds the reasoning.

## 1. Introduction

**In plain words:** Focus is the mark that shows which control the keyboard will act on. Without it, keyboard users are lost.

**Precisely:** Foundation. The focus ring: width, offset and colour. It is drawn on `:focus-visible` for every interactive component.

**The shape of the ring.** An outline of `focus.ring.width`, offset from the box by `focus.ring.offset`. The offset places the ring on the page and not on the control's own fill, so it stays visible on a filled primary button.

## 2. Usage

### When to use

- On every interactive component: buttons, fields, links, tabs (WCAG 2.4.7 Focus Visible, AA).

### When not to use, and what to use instead

- **On non-interactive containers.** Do not add `tabindex` only to show a ring.

### How

- **Tokens.** Draw the outline with the three tokens: `outline: var(--ds-focus-ring-width) solid var(--ds-focus-ring-color)`, and `outline-offset` from the offset token.
- **Contrast.** Keep the ring at 3:1 against the surface in both themes (WCAG 1.4.11 Non-text Contrast, AA).
- **Visibility.** Keep a focused control from hiding under a sticky header (WCAG 2.4.11 Focus Not Obscured, AA).

## 3. Why the states look as they do

The ring is the focus-visible state of every component. The browser shows `:focus-visible` after keyboard input and hides it after a mouse press, so mouse users see no ring and keyboard users always do. The ring is instant: a transition on it would delay the mark the user waits for.

## 4. Pitfalls and don'ts

- **Do not write `outline: none` with no replacement.** Keyboard users lose their place. (WCAG 2.4.7, AA; `focus.never-removed`)
- **Do not colour the ring like the fill.** It vanishes on the primary button. The offset prevents this. (WCAG 1.4.11, AA; `focus.ring-contrast`)
- **Do not draw a 1px ring.** It is hard to see for low-vision users. (House standard, 2px minimum; `focus.ring-min-width`)
