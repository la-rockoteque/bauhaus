# Stack

The Showcase story holds the tokens, the stage and the states grid. The Advisories story holds the live rulebook and the accessibility coverage. This guide holds the reasoning.

## 1. Introduction

**In plain words:** A stack puts things in a line, one after the other, with an even gap between them. The line runs down the page or across it.

**Precisely:** Primitive component. A flex Box with a direction, a gap step, cross-axis alignment, main-axis distribution and optional wrapping.

**The job.** Most layout is "these items, in a row or a column, this far apart". Stack says exactly that and nothing more. It builds on Box, so the gap is a space step and no other value can be written.

**The layer.** A primitive. It imports Box. Components use it for their inner layout.

## 2. Usage

### When to use

- To lay out siblings in one row or one column with an even gap.

### When not to use, and what to use instead

- **For a two-dimensional layout.** Use a Box with `display="grid"`.
- **To reorder content visually.** A stack has no reverse direction. Change the DOM order instead, so the reading order and the focus order match the visual order (WCAG 1.3.2 Meaningful Sequence, A; 2.4.3 Focus Order, A).

### How

- **Direction.** `vertical` is the default. `horizontal` runs along the inline axis, so it flips in right-to-left text without a change.
- **Gap.** A space step from 0 to 12. The default is 4, which is 16px in the default scale.
- **Alignment.** `align` acts on the cross axis, `justify` on the main axis. Both default to the CSS start behaviour, and `align` defaults to `stretch`.
- **Wrap.** Set `wrap` on a horizontal stack whose children vary in width, such as a row of buttons or tags. Without it, the row overflows at 320 CSS px (WCAG 1.4.10 Reflow, AA).
- **Lists.** Pass `as="ul"` or `as="ol"` and use `li` children when the items are alike. The stack resets the markers, the margin and the padding of the list. It also sets `role="list"`, since Safari drops list semantics from a list with `list-style: none`; pass another `role` to override it. Screen reader users then hear the item count (WCAG 1.3.1, A).
- **i18n.** Stack holds no text.

## 3. Why the states look as they do

A stack is not interactive. It has no hover, focus, active, disabled or selected look, and no loading or error form. An empty stack renders an empty flex container with no size, so the caller hides it when there is nothing to show.

## 4. Pitfalls and don'ts

- **Do not fake a reversed order with CSS.** Sighted users and keyboard users then see two different orders. (WCAG 1.3.2, A; `stack.no-reverse`)
- **Do not leave a row of buttons without `wrap`.** It scrolls sideways on a phone. (WCAG 1.4.10, AA; `stack.wraps`)
- **Do not use a div stack for a list of like items.** Use `as="ul"`. (WCAG 1.3.1, A; `stack.list-semantics`)
- **Do not write a margin between children.** Set the gap. (Project decision; `stack.gap-from-space`)
