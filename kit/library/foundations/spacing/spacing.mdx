# Spacing

The Showcase story holds the live scale and the semantic gaps. The Advisories story holds the live rulebook and the accessibility coverage. This guide holds the reasoning.

## 1. Introduction

**In plain words:** Spacing is the air between things. Close things read as one group. Far things read as separate. One fixed set of gaps keeps every screen in the same rhythm.

**Precisely:** Foundation. A closed scale of 13 steps on a 4px grid, plus semantic gap tokens. It governs margin, padding and gap. It is not a layout grid and not a control size.

**Two tiers.** Tier 1 is the scale. Base unit 4px. Every step is a multiple of it, so edges align across components. The scale is closed: no step exists between `space.4` and `space.5`, and a new step needs a scale proposal. Tier 2 names the job: inset, stack and inline. A component reads tier 2. It reads tier 1 only for a size that is not a gap, such as a spinner box.

## 2. Usage

### When to use

- Between and inside every block, through a tier 2 token (project decision: tokens are the only source of a value).

### When not to use, and what to use instead

- **To size a control.** Use the control scale: `size.control.sm` 24px, `size.control.md` 32px (the default), `size.control.lg` 40px. A control draws at `size.control.md`, and its target is at least `size.target.min`, 24px (WCAG 2.5.8 Target Size Minimum, AA).
- **To stack layers.** Spacing does not order layers. Use the z-index scale.
- **For a gap that only one component uses.** Keep it in that component, as a tier 1 step.

### How

- **Grouping.** Make the gap inside a group smaller than the gap between groups. Use `space.stack.sm` between a label and its value and `space.stack.lg` between groups (Wertheimer 1923, proximity).
- **Parent owns the gap.** Set the gap on the parent with `gap`, not as margins on the children, so stacks never collide (project decision, from `knowledge/foundations/spacing-layout.md`).
- **Small controls.** Space small controls so a 24px circle on each does not touch another (WCAG 2.5.8 spacing exception, AA).
- **Text.** Do not fix the height of a container that holds text. The text must survive line height 1.5 and paragraph spacing of 2× the font size (WCAG 1.4.12 Text Spacing, AA).
- **Reflow.** Keep one column and no second scroll axis at 320 CSS px (WCAG 1.4.10 Reflow, AA).

## 3. Why the states look as they do

Spacing has no interaction or lifecycle state. Two cells are decided:

- **Breakpoints are tokens, but a media query cannot read them.** `breakpoint.sm`, `md` and `lg` are 640, 768 and 1024px. A stylesheet writes the same number in `@media (max-width: 768px)`, and `spacing.breakpoints-match` fails when a width in any query equals none of the three. Change a breakpoint in the token file and in every query in one commit.
- **Compact is the default density.** The library ships one density, and it is compact: a control is 32px high, and the tier 2 scale runs `xs` 4, `sm` 8, `md` 12, `lg` 16, `xl` 24. A denser page never shrinks a target below `size.target.min`, 24px.
- **Buttons have flat padding.** A button and a button-like pressable (chip, tab, menu item, pagination item, segmented control, table sort, disclosure trigger) centres its label in `size.control.md`. Its `padding-block` is 0 and its `padding-inline` is `space.inline.md`, so the block padding is always below the inline padding (`button.padding-flat`). Containers such as cards, banners and popovers are not bound by this rule.
- **Raised text spacing is designed.** Gaps are tokens and no container around text has a fixed height, so a user who raises text spacing loses nothing.

## 4. Pitfalls and don'ts

- **Do not write `margin: 18px` at a call site.** It is off the scale, and gaps drift between screens. (Closed scale; `misfile.raw-value-in-component`; `spacing.no-literal`)
- **Do not use the same gap between and inside groups.** Groups stop reading as groups. (Wertheimer 1923; `spacing.groups-distinct`)
- **Do not fix the height of a card that holds text.** Text clips when the user raises text spacing. (WCAG 1.4.12, AA; `spacing.text-spacing-safe`)
- **Do not add a step "just this once".** The scale gains a hole, and every later step becomes arguable. (Closed scale; `spacing.scale-closed`)
- **Do not use a target smaller than `size.target.min` to save room.** Users miss it. (WCAG 2.5.8, AA; house floor 24px; `spacing.target-min`)
